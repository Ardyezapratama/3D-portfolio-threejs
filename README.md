<h3>3D Portfolio Website with Three.js</h3>

This project aims to study and gain practical experience in designing immersive web experiences, mastering 3D libraries, and implementing engaging animations. The tutorial is available on <a href="https://www.youtube.com/@javascriptmastery/videos" target="_blank"><b>JavaScript Mastery</b></a>.

## Tech Stack

- React.js
- Three.js
- React Three Fiber
- React Three Drei
- Vite
- Tailwind CSS
